# Что отправить в форму участника

Работу отправляет капитан команды в личном кабинете конкурса, блок «Моя работа».

| Пункт формы | Что отправить |
| --- | --- |
| 1. Ссылка на прототип и тестовые аккаунты | Текст ниже, в комментарий к работе |
| 2. Исходный код | Ссылка на репозиторий https://github.com/jeenien/e-dekanat (репозиторий должен быть открытым) или архив исходников на Яндекс Диске |
| 3. Описание процесса создания | Файл `docs/PROCESS.pdf` |
| 4. Видео (по желанию) | Сценарий — в `docs/VIDEO.md` |

```

Запасной адрес: https://109.120.152.121

Тестовые аккаунты (на странице входа есть кнопки «Демо-доступ», они подставляют логин и пароль):
• Студентка Анна Ветрова (ФУП, 2 курс, бюджет): anna / Orbita-Anna-2026

Демо-данные пересоздаются каждую ночь в 04:30 по Москве, поэтому даты всегда актуальные. Если основной кабинет грузится медленно, есть облегченная версия: /lite.
```

## Проверка перед отправкой

- [ ] Сайт открывается с телефона через мобильный интернет в России, без VPN, по обоим адресам.
- [ ] Вход под `anna` и `dekanat` работает.
- [ ] Репозиторий открыт (Settings → General → Danger Zone → Change visibility → Public) или приложен архив исходников.
- [ ] На сервере установлена последняя версия: `sh /opt/orbita/deploy/update.sh`.
- [ ] Перед отправкой выполнен сброс демо-данных: `systemctl start orbita-reset.service`.
- [ ] Сервер оплачен минимум до 28 ноября.
