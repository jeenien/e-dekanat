# Сценарий видео-демонстрации (до 5 минут)

Записывайте с телефона (запись экрана) или с компьютера в режиме телефона. Перед записью сбросьте демо-данные: `systemctl start orbita-reset.service`.

| Время | Что показать | Что сказать |
| --- | --- | --- |
| 0:00–0:20 | Страница входа | «Это "Орбита" — личный кабинет студента, где учеба, документы и связь с деканатом собраны в одном месте. Университет и данные вымышлены» |
| 0:20–0:50 | Вход как Анна, экран «Сегодня» | «Главный экран сразу отвечает, куда идти: следующая пара, изменения в расписании, дедлайны, пропуски и заявки» |
| 0:50–1:30 | «Расписание»: неделя, изменение, нажатие на пару | «Изменения подсвечены цветом. Пару можно открыть: аудитория, преподаватель и задания к ней» |
| 1:30–2:10 | «Учеба»: шкала, рейтинг, «Из чего складывается», «Сессия» | «Видно, из чего складываются баллы: срезы, посещаемость, работа на парах. От 70 баллов зачет автоматом» |
| 2:10–3:00 | «Заявки» → справка об обучении → «Получить сразу» → PDF → QR | «Справка готова сразу, в PDF, с QR-кодом. По коду любой может проверить подлинность» |
| 3:00–3:40 | Заявление на матпомощь → вход как деканат → смена статуса → снова Анна, лента | «Заявление уходит в деканат, сотрудник меняет статус, студент сразу получает уведомление» |
| 3:40–4:10 | «Посещаемость», «Лента» с мероприятием и «Добавить в календарь» | «Пропуски в академических часах, проходы через турникеты, мероприятия с проверкой пересечений с парами» |
| 4:10–4:40 | Вход как преподаватель: отметка посещаемости, задание к паре | «У преподавателя свой кабинет: посещаемость, задания, перенос пары через деканат» |
