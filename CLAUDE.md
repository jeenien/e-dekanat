# CLAUDE.md — инструкции для ИИ-агентов, работающих с «Орбитой»

Этот файл читают Claude Code и другие ИИ-ассистенты перед изменениями в проекте.

## Что это
Конкурсный прототип личного кабинета студента «Орбита — цифровой деканат». Вымышленный Университет «Горизонт».
**Все данные вымышлены.** Пометка о демонстрационном прототипе есть на странице входа (`login-note` в `public/js/app.js`) и водяным знаком на справках — не удаляйте их.

## Стек и структура
- Node.js ≥ 22.13, Express 4, встроенный `node:sqlite`. Фронтенд — ES-модули без сборки.
- `server/index.js` — приложение, заголовки безопасности, CSRF-проверка, статика.
- `server/auth.js` — вход, сессии, лимит попыток. `server/security.js` — scrypt, AES-GCM, токены.
- `server/api.js` — все маршруты `/api/*`. `server/services.js` — расписание, баллы, уведомления.
- `server/requests.js` + `server/catalog.js` — услуги деканата; схема формы задается в каталоге и используется и фронтом, и сервером.
- `server/documents.js` — справки с QR и страница `/verify/:code`. `server/assistant.js` — помощник (Claude или локальные правила).
- `server/seed.js` — демо-данные; даты считаются от «сегодня». `server/schedule-data.js` — расписание групп по открытым данным вуза (без ФИО преподавателей).
- `server/campus-api.js` — мероприятия (лента, календарь, пересечения), задания к парам, кабинет преподавателя (роль `teacher`), согласование переносов деканатом. `server/statements.js` — типовые заявления в PDF (pdfkit, шрифт Liberation Serif, OFL).
- `server/lite.js` — облегченная версия `/lite` без JavaScript; права те же, что в API. Действия с заявками и переносами — в `server/workflows.js`, общем для обеих версий. `public/js/boot.js` предлагает ее при медленной загрузке.
- Время пар и шкала оценок (проценты → 5-балльная → ECTS) — в `server/academic.js`.
- `public/js/views/*.js` — экраны. `public/js/lib.js` — `esc()`, `icon()`, `api()`, даты, тосты, модальные окна.

## Непреложные правила
1. **Личность — только из сессии.** Никогда не берите id студента из URL, query или тела запроса. Любой объект ищите с условием `student_id = req.user.id`; чужое → 404 (не 403, чтобы не раскрывать существование). Преподаватель работает только со своими парами (`teacher_subjects`).
2. **Любой текст в HTML — через `esc()`.** Никаких `innerHTML` с сырыми данными. CSP запрещает inline-скрипты — не добавляйте их.
3. **Изменяющие запросы** идут через `api()` из `lib.js` (он ставит заголовок `X-Orbita: 1`).
4. **Секреты** только в переменных окружения (`DATA_KEY`, `ANTHROPIC_API_KEY`). Ничего не коммитьте в `data/`.
5. **Персональные поля** (зачетка, e-mail, телефон, дата рождения) хранятся зашифрованными (`encrypt/decrypt`). В ИИ их не передаем — см. `contextText()` в `assistant.js`.
6. **Только вымышленные данные.** Не добавляйте реальные ФИО, вузы, логотипы.
7. Тексты интерфейса — на русском, коротко и по-человечески, без канцелярита.
8. Без буквы «ё» в текстах; формулировки нейтральные («баллов недостаточно», а не «уже не хватит»). Без градиентов: стиль «жидкое стекло», акцент — `--accent` (navy по умолчанию).
9. Мобильная ширина от 360 px: после правок верстки запускайте `npm run screenshots` и проверяйте, что нет горизонтальной прокрутки.

## Проверка перед коммитом
```bash
npm test                 # 21 тест: безопасность и ключевые сценарии
npm run reset-db && npm start &   # затем:
npm run screenshots      # сквозной прогон в браузере + скриншоты в docs/screenshots
```

## Как добавить новую услугу деканата
Добавьте запись в `TYPES` в `server/catalog.js` (поля: `title`, `group`, `icon`, `description`, `sla_days`, `fields`). Форма, валидация, статусы и переписка заработают автоматически. Иконка — ключ из `public/js/icons.js` (новые — через `scripts/build-assets.js`).
